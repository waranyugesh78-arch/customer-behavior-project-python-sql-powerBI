# 🛍️ Customer Behavior Analysis — SQL + Power BI

An end-to-end data analytics project that explores customer purchasing behavior using **SQL** for data analysis and **Power BI** for interactive visualization. The project answers key business questions around revenue, discounts, customer segmentation, shipping preferences, and subscription trends.

![Dashboard Preview](powerBI_dashbord.png.png)

---

## 📌 Project Overview

This project analyzes a customer transactions dataset (3,900+ records) to uncover patterns in purchasing behavior, product performance, and customer loyalty. The workflow covers:

1. Writing SQL queries to answer specific business questions
2. Cleaning and modeling the dataset
3. Building an interactive Power BI dashboard for stakeholders

---

## 🗂️ Dataset

The dataset contains customer-level transaction data with the following fields:

| Column | Description |
|---|---|
| `customer_id` | Unique customer identifier |
| `age`, `gender`, `location` | Customer demographics |
| `item_purchased`, `category` | Product details |
| `purchase_amount` | Transaction value |
| `size`, `color`, `season` | Product attributes |
| `review_rating` | Customer's product rating |
| `subscription_status` | Whether the customer is subscribed |
| `shipping_type` | Delivery method chosen |
| `discount_applied`, `promo_code_used` | Discount/promo details |
| `previous_purchases` | Number of past purchases |
| `payment_method` | Payment mode used |

## 🎯 Business Questions Answered (SQL)

| # | Question |
|---|---|
| Q1 | What is the total revenue generated by male vs female customers? |
| Q2 | Which customers use discounts but still spend more than the average purchase amount? |
| Q3 | Which are the top 5 products with the highest average review rating? |
| Q4 | How does average purchase amount compare between standard and express shipping? |
| Q5 | Do subscribed customers spend more? (avg spend & total revenue: subscribers vs non-subscribers) |
| Q6 | Which 5 products have the highest percentage of purchases with discounts applied? |
| Q7 | Segment customers into New, Returning, and Loyal based on previous purchases |
| Q9 | Are repeat buyers (more than 5 previous purchases) more likely to subscribe? |

> All SQL scripts are available in the [`/sql`](./sql) folder, using window functions, CTEs, subqueries, and aggregate functions.

**Sample query — Customer Segmentation (Q7):**
```sql
with customer_type as(
select customer_id, previous_purchases,
case
    when previous_purchases = 1 then 'new'
    when previous_purchases between 2 and 10 then 'returning'
    else 'loyal'
end as customer_segment
from customer
)
select customer_segment, count(*) as "number of customers"
from customer_type
group by customer_segment;
```

## 📊 Power BI Dashboard

An interactive **Customer Behavior Dashboard** was built to visualize key metrics and allow filtering by subscription status, gender, category, and shipping type.

**Key Metrics (KPIs):**
- 👥 Number of Customers
- ⭐ Average Review Rating
- 💵 Average Purchase Amount

**Visuals included:**
- % of customers by subscription status (donut chart)
- Revenue by product category
- Sales volume by product category
- Slicers for `subscription_status`, `gender`, `category`, and `shipping_type`

📁 Dashboard file: [`customer_behavior_dashboard.pbix`](./dashboard)

---

## 🧠 Key Insights

- Revenue and spending patterns differ noticeably between subscribers and non-subscribers.
- A specific segment of customers uses discounts frequently while still spending above average — a strong upsell target.
- Clothing and Accessories are the top-performing categories by both revenue and sales volume.
- Customer loyalty (based on purchase history) does not always align directly with subscription behavior.
